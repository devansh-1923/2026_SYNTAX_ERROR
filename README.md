# Habitax

### Build Better Habits. Stay Consistent.

Habitax is a modern habit-tracking web application designed to help users build positive habits, maintain consistency, and monitor their personal progress through an engaging and intuitive interface.

## ✨ Features

* 📌 Create and manage habits
* 🔥 Track daily streaks
* 📊 Monitor habit progress
* 🎯 Set personal goals
* 💾 Save habit data
* ✨ Interactive animations and modern UI
* 📱 Responsive design

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript**
* **Local Storage**

## 🎯 Purpose

Habitax makes habit tracking simple, visual, and engaging. Instead of relying on basic checklists, users can track their consistency and see their progress over time.

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Open the project in VS Code and run `index.html` using Live Server.
